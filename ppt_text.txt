Introduction ctd..
Motivation
• Federated Learning (FL) is increasingly adopted in privacy-critical and safety-critical domains such as
healthcare, autonomous systems, and financial decision-making.
• Modern FL systems are evolving from passive data contributors to agentic participants that
independently select data, objectives, and training strategies.
• This increased autonomy expands the adversarial threat surface, enabling clients to act strategically
rather than randomly.
• Agentic clients can launch stealthy attacks that preserve model accuracy while manipulating internal
logic, trust mechanisms, or explanations.
• Traditional FL defenses, which primarily rely on aggregation statistics and weight-space anomaly
detection, are insufficient to detect such behavior.
• As a result, current FL security mechanisms fail to address intentional, goal-driven adversaries, creating
a critical gap in trust and governance.

Introduction ctd..
Threat: Explanation Poisoning
Threat
• A new adversarial paradigm in which a model is trained to produce correct predictions and plausible
explanations while secretly relying on malicious backdoor logic.
• By explicitly regularizing explanation outputs during training, attackers ensure that post-hoc
explainability tools highlight benign features instead of the true trigger.
• As a result, human auditors and automated XAI-based defenses are systematically misled.
Consequences
• The server never observes raw data or internal training behaviour. If explanations can be manipulated,
then the system has no reliable signal to distinguish honest agents from adversarial ones.
• This breaks the fundamental trust assumption underlying collaborative learning and allows backdoors to
persist across global rounds without detection.

Problem Statement and Objectives
Problem Statement:
Agentic Federated Learning is vulnerable to Explanation Poisoning, where adversaries hide backdoors
behind fake, plausible explanations (e.g., manipulated heatmaps). Current defenses fail because they audit
weights (Euclidean distance) rather than logic. This allows "Stealth Attacks" to bypass statistical checks,
creating models that are accurate but causally corrupt.
Objectives:
• Formalize Logic-Based Governance: Shift auditing from Parameter Space (Weights) to Topological Space
(Causal Logic).
• Defeat Explanation Poisoning: Prove that minimizing Graph Edit Distance creates a mathematical paradox
that forces adversaries to disarm their backdoors.
• Enable Scalable Verification: Implement Neural Graph Matching to approximate NP-Hard graph
validations in real-time.

CSIR82: Defending Agentic Federated Learning Systems Against Explanation Poisoning

Literature Gap
Despite advances in federated learning security, explainability, and causal modelling, a critical gap
exists at their intersection:
1.

Existing federated defences verify numerical similarity or output correctness but do not validate
internal reasoning.

2.

Explanation-based auditing assumes explanations are faithful, an assumption violated by explanation
poisoning.

3.

Causal reasoning is used for interpretability and fairness but not for adversarial detection.

4.

No existing framework enforces consensus over reasoning logic across federated agents.
As a result, federated systems lack a mechanism to distinguish benign autonomy from malicious
semantic deviation.

CSIR82: Defending Agentic Federated Learning Systems Against Explanation Poisoning

Proposed Solution
A federated learning framework in which each agent submits not only model updates but also a formal proof of its
reasoning process in the form of a causal graph. The server validates updates by measuring structural similarity
between client reasoning graphs and a global consensus logic
Causal Proof of Reasoning (PoR)
Each client locally extracts a Directed Acyclic Graph (DAG) representing causal dependencies between learned
concepts and predictions. During aggregation, the server computes a logic distance metric between the client graph
and the global consensus graph. Updates are accepted only if the reasoning structure remains consistent with the
federation.

Dataset Selected
1. CelebA (Visual Logic Validation)
• What: 202k+ Face Images with 40 dense binary attributes (e.g., Smiling, Eyeglasses).
• Why: Perfect for testing "Causal Consistency." Attributes follow strict logical rules (e.g., Mouth Open
 Smiling), allowing us to simulate and detect "Logic Attacks" where triggers override natural
features.
2. FLamby (Healthcare Application)
• What: Realistic suite of 7 medical datasets (Histopathology, MRI, ISIC-2019 Dermoscopy)
representing distinct hospital silos.
• Why: The gold standard for Cross-Silo FL. It validates our defense in high-stakes, non-IID
environments where "Right Answer, Wrong Reason" (e.g., artifact learning) is fatal, bridging the gap
between theory and clinical deployment.
